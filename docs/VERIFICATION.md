# 검증 기록 (공통 원칙 §6 순서)

최종 갱신: 2026-09-23. 대상: P0 정적 웹앱 (`index.html`+`engine/`+`app.js`).

## 1. 모델 검증 — 통과

- `npm test` 9/9 (Node 24, `tests/engine.test.mjs`).
- 모든 모드 확률 ≥0, 합 1 (실측 편차 4.5e-16, 목표 1e-12 이내), CDF 끝값 1.
- φ=0 간섭 분포: 중앙 2칸(255·256, 짝수 칸이라 x=0을 나눔)이 공동 최대. φ=π: 중심 최소 (중심 3.97e-6 vs 최대 9.13e-3).
- 간섭 소실·한 슬릿: φ 변경 시 분포 차이 0.
- 같은 seed 100회 = 1000회 앞 100회 일치 (난수 2개/표본 소비 규칙 고정).
- 다중 seed(5개) 평균 MAE: N=100 (2.4e-3대) > N=10000 (2.9e-4대). 작은 N을 이론 곡선에 맞추지 않음.

## 2. 데이터 검증 — 통과

- 레코드에 schemaVersion·appId·scenarioId·parameters·seed·N·counts·관찰·예측·한계 포함. 새로고침 뒤 localStorage 2건 유지 확인.
- JSON 내보내기 다운로드 동작 확인. 개인 식별 정보 없음.

## 3. UI 검증 — 통과

- 실제 흐름 1→100→1000→10000·A·B 비교·기록 저장을 Playwright 실브라우저로 수행. 콘솔 오류 0, 실패 리소스 0.
- 키보드만으로 예측·누적 실행·기록 저장 가능. 포커스 테두리 3px 확인. 다이얼로그 Esc 닫기·포커스 복귀.
- 320·390·768·1440px 가로 넘침 없음 (390px 그리드 `min-width` 수정 1건 반영).
- `prefers-reduced-motion` 정적 테두리 (CSS, 코드 검토). 320px 그래프·표 대체 표시 확인.
- 증거: `docs/qa/qa-desktop-1440.png`, `qa-tablet-768.png`, `qa-mobile-390.png`.

## 4. 성능 검증 — 통과 (데스크톱 Chrome headless)

- N=10000 누적 약 105ms (청크 1000, 진행률·취소 가능). 일반 입력 반응은 청크 사이 양보로 100ms 내 유지.
- 탭 숨김 시 계산 일시정지 + 재개 문구 표시. N=1000 이론·관측 렌더 즉시.
