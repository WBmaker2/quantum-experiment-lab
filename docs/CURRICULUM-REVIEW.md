# 교과 검토서 (물리교육 관점)

- 검토일: 2026-09-23 / 검토자: 주 에이전트 (물리교육 전공 관점 대리 검토 — 최종 수업 적용 전 교사 검토 권장)
- 대상: P0 앱 전체 + `11-quantum-experiment-lab.md` §2(오개념)·§5(모형)
- 방법: 모형식을 손으로 전개해 앱 문구·그래프와 대조, 오개념 유발 지점 점검

## 모형 전개 (검토 근거)

ψ1 = g·e^(iκx/2), ψ2 = g·e^(−iκx/2+iφ), g(x) = e^(−x²/36)

- 간섭 유지: |ψ1+ψ2|² = 2g²(1+cos(κx−φ)) → φ=0 중심 최대, φ=π 중심 최소 ✓
- 간섭 소실: |ψ1|²+|ψ2|² = **2g² (무늬 없는 단일 봉우리)**
- 한 슬릿: |ψ1|² = g² → 정규화 후 간섭 소실과 **완전히 동일**

## F1 — 오류: "간섭 소실 = 두 봉우리의 합" (수정 완료)

- 문제: 두 경로의 포락선 g(x)가 같으므로 결코herent 합은 봉우리 하나다. "두 봉우리"는 떨어진 실제 슬릿의 회절포락선을 떠올리게 하며, 학생이 직접 실행하면 봉우리 하나가 나와 앱 설명과 모순된다.
- 조치: 설명문을 "무늬 없는 하나의 봉우리 (두 경로 확률의 합)"로 교체. 예측 선택지 "두 봉우리의 합"은 대표 오개념(알갱이 두 무더기 예상)을 진단하는 오답이므로 **유지** — 단, 본 검토서에 근거를 남김.

## F2 — 누락: 한 슬릿 vs 간섭 소실이 P0에서 구별 불가 (추가 완료)

- 문제: 정규화 때문에 두 모드의 모양이 완전히 같다. 전이 과제("한 슬릿 닫음 vs 경로 정보 두 슬릿 구분")와 연결하려면 이 한계를 밝혀야 하며, 설계 §5도 "통과율 차이는 P0에서 비교하지 않는다"고 못 박았다.
- 조치: 예측 설명 + 조건 비교 안내에 "P0 모형에서는 한 슬릿과 모양이 같게 나오며, 둘의 차이는 통과율인데 P0에서 비교하지 않는다"를 명시.

## F3 — 누락: 점의 세로 위치 무의미 (추가 완료)

- 문제: 검출면 점들의 y 흩뿌림(가시성용 지터)이 세로 물리량으로 오독될 수 있다.
- 조치: 검출면 힌트에 "점의 세로 위치는 겹쳐 보이지 않게 흩뿌린 것으로, 물리량이 아니다"를 추가.

## F4 — 가독성: 지수 표기 → 소수 표기 (적용 완료)

- 문제: `1.04e-2`, `MAE=7.86e-4`는 고등학생에게 어렵다.
- 조치: 0.0001 이상은 소수 4자리, 미만만 지수 표기. 첫 등장하는 MAE는 "평균오차(MAE)"로 풀이.

## 통과 항목 (수정 없음)

- P1 진폭 합 vs 확률 합 구분 표현 정확. P2 개별 사건/누적 분포 구분. P3 "의식 효과 아님, 환경 상호작용 단순 모형" 문구 정확.
- P4 궤적 미표시 + 명시. P5 "검출된 사건의 위치 분포에 조건부" y축 표기. P6 κ·φ 단위·범위, 실측 대응 암시 금지.
- P7 작은 N 단정 금지 (비교 안내 + 기록 예시). P8 전이 과제 제시.
- 의견: κ 명칭 "상대 공간 진동수"는 단위(rad/모형길이)가 함께 있어 허용. "진폭의 합"이 복소진폭 합 후 제곱임은 기록 예시("진폭을 먼저 합하기 때문")로 보완됨.
