# 성능 측정 절차 (공통 §6.4)

- 목표: 일반 입력 반응 100ms 내, 무거운 계산은 진행·취소 표시.
- 앱이 계산 시간을 직접 보여준다: 누적 완료 문구 끝의 "계산 Nms" (performance.now 실측, 샘플링 구간만).

## 크롬북(저사양 실기기)에서 재는 법

1. 공개 URL(또는 로컬 `npm run serve`)을 시크릿 창에서 연다.
2. 초기 표시: 주소 입력 후 첫 화면이 다 보일 때까지 눈으로 3회 재서 적는다 (DevTools 없어도 됨).
3. 조건 그대로 N=10000 누적 실행 → 완료 문구의 "계산 Nms"를 3회 적는다.
4. N=1000 실행 중 취소 버튼이 눌리는지 확인한다.
5. 아래 양식으로 결과를 알려주면 VERIFICATION §4에 기록한다.

```
- 기기: (예: 학교 크롬북, 모델·RAM)
- 초기 표시: N / N / N ms
- N=10000 계산: N / N / N ms
- 취소 가능: 예/아니오
```

## 데스크톱 기준값 (2026-09-23, headless Chrome)

- N=10000 누적 약 105ms, N=1000 즉시. 청크 1000·진행률·취소 동작 확인.
