# P1 근거 노트 (단위·가정 검토)

- 작성일: 2026-09-23 / 상태: 구현 근거 확정. 설계 `11-quantum-experiment-lab.md` §9의 "단위와 가정 검토 후 추가"를 이 문서로 수행한다.
- 원칙: 식을 새로 꾸미지 않는다. 설계에 적힌 γ식과 표준 Fraunhofer 이중슬릿식만 쓴다.

## 1. 부분 간섭 γ (모형 단위)

설계식: rawP = |ψ1|² + |ψ2|² + 2γ·Re(ψ1*·conj(ψ2)), γ∈[0,1].

본 앱의 ψ1 = g·e^(iκx/2), ψ2 = g·e^(−iκx/2+iφ) 를 대입하면

- ψ1*·conj(ψ2) = g²·e^(i(κx−φ)), 실수부 = g²·cos(κx−φ)
- **rawP = 2g²·(1 + γ·cos(κx−φ))**

극한 일치 (회귀 테스트로 고정):

- γ=0 → 간섭 소실 모드와 정규화 후 완전히 동일
- γ=1 → 간섭 유지 모드와 정규화 후 완전히 동일

γ의 물리적 뜻은 "두 경로의 결어긋남 정도"이며, P1 UI에는 '경로 정보가 부분적일 때 무늬가 옅어지는 손잡이'로만 설명한다. 결어긋남의 미시적 기전(어떤 환경과 어떻게 얽혔는지)은 P1에서 설명하지 않는다 — 오개념(의식 효과)으로 번지지 않게 guard 문구를 둔다.

## 2. 원거리(Fraunhofer) 근사 오버레이 (실제 단위)

표준 이중슬릿 원거리 강도식만 사용한다 (교과서 공통 형태):

- I(θ) = cos²(π·d·sinθ/λ) · sinc²(π·a·sinθ/λ), sinc(u) = sin(u)/u (u=0에서 1)
- d = 슬릿 중심 간격, a = 슬릿 폭(유한폭 효과 = 이 sinc 포락선), λ = 파장, θ ≈ y/L (소각 근사)

입력(실제 단위, P1 기본값은 교실 적색 레이저 가정):

| 입력 | 기호 | 기본값 | 허용 범위 |
|---|---|---|---|
| 파장 | λ | 650 nm | 380–780 nm (가시광으로 제한, 근거: 교실 광원) |
| 슬릿 간격 | d | 0.5 mm | 0.05–2 mm |
| 슬릿 폭 | a | 0.1 mm | 0.01–d mm (a ≤ d 강제, 근거: 겹치지 않는 두 슬릿) |
| 거리 | L | 1.0 m | 0.2–5 m |
| 검출면 반폭 | Y | 5 mm | 고정 (512칸 분해능과 맞춤) |

가정·한계 (UI에 그대로 명시):

1. 원거리 조건(Fresnel 수 a²/(λL) ≪ 1)을 가정한다. 기본값에서 a²/(λL) ≈ 0.015로 조건 만족. 입력이 조건을 벗어나면(≥0.1) 경고를 띄우고 계산은 하되 "근사 신뢰 낮음"을 표시한다.
2. x축은 각 모형의 검출면이며 **물리적 스케일이 다르다.** 모형 x∈[−10,10]과 근사 y∈[−5,5]mm를 같은 칸 index에 겹쳐 그리지 않고, 별도 그래프에 둔다 (거짓 대응 방지).
3. 정규화는 각자 검출면에서 하며, 통과율(총 광량) 비교는 하지 않는다 (P0 원칙 유지).
4. 유한폭 효과는 sinc 포락선으로 구현한다. 모형 단위의 별도 폭 계수는 두지 않는다 (중복 방지, 근거: 같은 물리를 두 번 설명하지 않음).

## 3. 검증 대응 (tests/)

- γ=0/1 극한 일치 (정규화 후 차이 0)
- Fraunhofer: 확률 ≥0·합 1(1e-12)·대칭 I(y)=I(−y)·a→0 극한에서 순수 cos²에 수렴
- 입력 가드: a>d, λ 범위 밖, L 범위 밖, 비유한 값 → 중단
